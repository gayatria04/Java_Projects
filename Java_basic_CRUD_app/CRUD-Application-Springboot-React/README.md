# CRUD Application - Spring Boot + React

A simple full-stack CRUD (Create, Read, Update, Delete) application built using **React** for the frontend and **Spring Boot** for the backend.

The application allows users to be created, viewed, updated, and deleted through a REST API.

## Tech Stack

### Frontend
- React
- Axios
- React Router
- Bootstrap

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- Maven

### Database
- MySQL

#### Features

Create a user
View all users
View a user by ID
Update user information
Delete a user
React frontend connected to Spring Boot REST API
MySQL database integration
CORS configuration for frontend-backend communication


#### REST API Endpoints

Method  Endpoint	Description
POST	/user	    Create a new user
GET	    /users	    Get all users
GET	    /user/{id}	Get user by ID
PUT	    /user/{id}	Update a user
DELETE	/user/{id}	Delete a user
